Before you add

Get the device ready for NetOps Center

  1. 1
    Enable SSH on the device and create a local user for NetOps Center.
  2. 2
    Send syslog to this server so config changes show up on the dashboard.
    Cisco / Arista / Aruba
    logging host {{ server_ip }}{% if system_settings.syslog_port != 514 %} transport udp port {{ system_settings.syslog_port }}{% endif %}
logging trap informational
    MikroTik RouterOS
    /system logging action set [find name=remote] remote={{ server_ip }} remote-port={{ system_settings.syslog_port }}
/system logging add topics=info action=remote
/system logging add topics=warning action=remote
/system logging add topics=error action=remote
/system logging add topics=critical action=remote
  3. 3
    Use the management IP, the one the device sends syslog from, so its logs are matched to it.
